# SegmentIQ AI

## Customer Segmentation & Business Intelligence Dashboard

SegmentIQ AI is an interactive machine learning dashboard that groups customers into meaningful segments based on their purchasing behavior.

The project uses **K-Means Clustering** to identify customer groups and provides business insights that help understand customer value, purchasing frequency, spending, and engagement.

---

## 🎯 Project Objective

The main objective of SegmentIQ AI is to analyze customer purchasing behavior and divide customers into different groups using unsupervised machine learning.

The dashboard helps answer questions such as:

- How many customers are being analyzed?
- Which customers purchase more frequently?
- Which customers generate higher spending?
- Which customers may need re-engagement?
- What characteristics are common within each customer segment?

---

## 🚀 Key Features

### 🏠 Executive Dashboard

Provides an overall view of the customer base with:

- Total customers
- Number of customer segments
- Average customer spending
- Average orders
- Segment distribution
- Customer segment summary

### 🔍 Customer Explorer

Allows users to explore individual customers using:

- Customer ID search
- Segment filtering
- Recency
- Purchase frequency
- Monetary value
- Total quantity
- Product variety
- Average order value

### 🧩 Segment Intelligence

Provides detailed profiles of each customer segment and compares their purchasing behavior.

### 📊 Clustering Analysis

Shows the machine learning analysis used to select the number of clusters, including:

- Elbow Method
- Inertia
- Silhouette Score
- K-Means clustering comparison

### 🧠 PCA Visualization

Uses Principal Component Analysis (PCA) to visualize high-dimensional customer data in two dimensions.

The first two principal components explain approximately **83.80%** of the variance.

### 💼 Business Insights

Converts clustering results into easy-to-understand business recommendations such as:

- Customer retention
- Re-engagement
- Loyalty programs
- Cross-selling
- Upselling
